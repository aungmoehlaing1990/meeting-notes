Meeting Notes — Help

Overview

Record the meeting on your phone (audio + photos). Open this app after the meeting to create a structured note. This app runs fully offline in your browser. For automatic transcription, it talks to a local Whisper server on your own machine — no cloud, no API billing.

Typical workflow

  1. End the meeting. Save the audio recording and photos from your phone.
  2. Start the local transcription server (see setup below).
  3. Open this app (on phone or desktop). Tap "New Meeting".
  4. Import the audio file and photos (from your device).
  5. Tap 🔊 Transcribe in the Audio Recording section. The server transcribes with Whisper large-v3, identifies speakers (Speaker 1, 2, 3…), extracts decisions, action items, topics, and next steps. It fills the form automatically.
  6. Light edit: fix names, numbers, and any wrong speaker labels.
  7. Fill in title, date, attendees.
  8. Save. Export .docx to share with superiors (photos embedded). Export Markdown for your archive.

Setting up the transcription server (one-time, on your desktop)

The Transcribe button sends your audio to a small Python server (whisper_server.py, included with this app) that runs Whisper large-v3 (best local transcription) plus pyannote speaker diarization (who said what → Speaker 1, Speaker 2, …).

Step 1: Prerequisites

  1. Python 3.11+ installed (you have 3.11.15).
  2. ffmpeg on your PATH (required by Whisper and pyannote):
    • Windows: run winget install Gyan.FFmpeg in a terminal. Important: pyannote also needs FFmpeg's shared DLLs (avcodec-XX.dll etc.). The whisper_server.py that ships with this app looks for a ffmpeg\bin folder next to it and adds it to PATH automatically — that folder is included in the GitHub repo, so if you clone the repo you get it for free. If you run the script from elsewhere, make sure an FFmpeg build with shared DLLs is reachable (the repo's ffmpeg/ folder works).
    • Verify: ffmpeg -version should show version info.
  3. HuggingFace account + free token (required by the pyannote speaker models):
    • Create an account at huggingface.co.
    • Create a token at huggingface.co/settings/tokens (default "read" scope is fine).
    • Accept the user agreements on three pyannote model pages (the pipeline uses all three, and each is gated separately): pyannote/speaker-diarization-3.1, pyannote/speaker-diarization-community-1, pyannote/segmentation-3.0.

Step 2: Install

pip install flask openai-whisper pyannote.audio

Also make sure the torch dependency installed cleanly (it comes with whisper). First run of the server downloads: Whisper large-v3 (~2.9 GB, once) and the pyannote models (~1 GB, once). Subsequent starts use the cache — no re-download.

Step 3: Run the server (each time before transcribing)

python "C:\Users\Aung moe Hlaing\whisper_server.py" --hf-token YOUR_TOKEN

Wait until you see "Server starting on http://127.0.0.1:8765" in the terminal. Keep this window open while you transcribe. (You can also set the HF_TOKEN environment variable instead of --hf-token.)

Step 4: In the app

  • Tap ⚙️ (settings) in the top-right of the notes list. The server URL defaults to http://127.0.0.1:8765. Tap "Test Connection" to confirm it reaches the server, then "Save".
  • In the editor, import your audio, then tap 🔊 Transcribe. On CPU, large-v3 can take several minutes for a long recording — the status text will tell you it's working.
  • Results fill in automatically: speaker-labeled transcript, decisions, action items (owner extracted when it says "X will do Y"), detected topics, and next steps / follow-ups — shown in the "AI Report" section and the editable Decisions / Action Items fields.

Optional: enable the local LLM for professional-grade reports (recommended)

Pattern-based extraction is a first draft. For a real executive summary, conclusions, and sharper action items, run Ollama (a free, local LLM runner — no cloud, no API key) and restart the server with --llm. The server calls the LLM through its OpenAI-compatible API and replaces the heuristic results with the LLM's.

winget install Ollama.Ollama        # or install from ollama.com
ollama pull llama3.1:8b             # first run downloads the model (~4.7 GB)

Then start the transcription server with the LLM enabled:

python "C:\Users\Aung moe Hlaing\whisper_server.py" --hf-token YOUR_TOKEN --llm

Notes: defaults are --llm-url http://localhost:11434/v1 and --llm-model llama3.1:8b. Use a bigger model (llama3.1:70b) if your GPU/RAM handles it, or a smaller one (e.g. qwen2.5:7b) for slower machines. If the LLM is down or errors, the server automatically falls back to pattern-based extraction, so Transcribe always works.

What the intelligence layer does (and doesn't) do

  • Speaker labels (Speaker 1/2/3…) come from acoustic diarization. They are consistent within the recording but unlabeled — you'll want to mentally map "Speaker 1 = Jane". Fixing labels in the transcript text is quick.
  • Without --llm: decisions / action items / topics / next steps come from keyword + pattern matching. They catch the obvious but can miss or mis-catch — a first draft.
  • With --llm: the local LLM reads the whole speaker-labeled transcript and produces an executive summary, conclusions, topics, decisions, action items (with owners and due dates), and what's expected at the next meeting. Much closer to a professional report — but still verify names, numbers, and commitments before sharing.

On the phone

The app is fully usable on the phone (import, edit, export). For automatic transcription from the phone, run the Whisper server on your desktop and set the server URL to your desktop's LAN address (e.g. http://192.168.x.x:8765) — phone and desktop must be on the same Wi-Fi. Note: large audio uploads over Wi-Fi can take a while. Alternatively transcribe on the desktop and move the note to the phone via Export Note / Import Note.

Export formats

  • .docx (primary): Full note with embedded photos, action items table, decisions. Share this with superiors. The audio file is not embedded in the .docx — keep the audio file alongside it if needed.
  • Markdown (secondary): Same content in Markdown. Photos are referenced by filename (not embedded). Good for your own archive and other tools.
  • Export Note (transfer): Exports one meeting note as a JSON file (with photos and audio encoded). Import it on another device to move the note between phone and desktop.

Notes storage

Notes are stored locally in your browser's IndexedDB. They are not synced to the cloud. To move notes between devices, use "Export Note" / "Import Note". Clearing browser data clears your notes.

Keyboard shortcuts

  • On desktop, press Esc to go back to the notes list from the editor.
